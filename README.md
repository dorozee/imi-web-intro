## Описание

Страница получает публикации с открытого API jsonplaceholder и отображает их в виде карточек.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Fetch API и GET-запросы
- Async/await и JSON
- Git и GitHub

## API

`https://jsonplaceholder.typicode.com/posts`

Ключ API не требуется.

## Возможности

- Загрузка списка публикаций.
- Отображение сообщения «Загрузка…» во время запроса.
- Проверка HTTP-ответа с помощью `response.ok`.
- Обработка сетевых ошибок и неуспешных HTTP-ответов.
- Повторная загрузка по кнопке «Обновить».
- Адаптивная вёрстка для мобильных устройств.

## Запуск проекта

Не открывайте `index.html` напрямую через `file://`. Запустите страницу через локальный HTTP-сервер.

### Вариант 1: Visual Studio Code и Live Server

1. Откройте папку проекта в Visual Studio Code.
2. Установите расширение Live Server.
3. Нажмите правой кнопкой мыши на `index.html`.
4. Выберите **Open with Live Server**.

### Вариант 2: Python

Если Python установлен, откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`.
